Assembly Guide

Required Components

Wemos D1 Mini (ESP8266 board) NEO-6M/7M GPS module 3-wire servo cable (JST-ZH 1.5mm or standard) Velcro strap & heat shrink tubing (40mm diameter)

Wire Connections

GPS TX → Wemos D1 Mini D4 (Serial RX) GPS V+ → Wemos D1 Mini 5V (V+) GPS V- → Wemos D1 Mini GND (V-) Servo Cable Red → Wemos D1 Mini 5V (V+) Servo Cable Black → Wemos D1 Mini GND (V-)

Final Assembly

Stack the gps module atop the Wemos development board and affix with foam tape. Slide the assembly along with a velcro strap into heat shrink tube (leave USB exposed). Use heat gun until tightly sealed. PRO TIP: Add a battery shield and 3d printed case for the ultimate SPEED_LINK build!

Flash Firmware

Connect the SPEED-LINK module to USB. Flash the downloaded binary using the ESP Web Flasher. Default settings are fine.
