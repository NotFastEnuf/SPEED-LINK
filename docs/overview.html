Overview

SPEED-LINK ...built for RC enthusiasts seeking real-time performance analytics

SPEED-LINK transforms any RC vehicle experience with live GPS telemetry through an open-source hardware/software solution. The system tracks top speed (100mph+ capable), calculates jump or climb heights, officiates and records drag race times, and displays data through a modern browser interface. Compatible with any RC model using standard receiver power ports or take it to the next level with a battery shield and 3D printed case.
